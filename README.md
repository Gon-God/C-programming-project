# C-programming-project

### The requirement folder shows the requirement of the project

This project requires developing a UIC classroom booking system in C. 

Users must log in with a username and password. After logging in, they can select available booking time.

After entering the required classroom size, the system assigns the smallest available classroom that meets the requirements. 

The system must use structures to manage classroom numbers, time slots, booking status, and the person who made the booking.

Then save the booking information for the most recent three days in a text file corresponding to each classroom.
